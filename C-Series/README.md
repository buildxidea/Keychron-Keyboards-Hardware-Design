# C Series - Hardware Design Files

> Wired C-series mechanical keyboards with approachable layouts, USB-C connectivity, and Mac/Windows support.

Part of the [Keychron Keyboards Hardware Design](https://github.com/Keychron/Keychron-Keyboards-Hardware-Design) repository.

## Available Models

| Model | Layout | Size | Connection | Status |
|---|---|---|---|---|
| [C1](./C1/README.md) | TKL | 87-key | USB-C wired | Files published |

## Repository Contents

This series folder currently contains:

- [C1](./C1/README.md)

## Download Files

| File | Description | Format |
|---|---|---|
| **Case** | Top and bottom enclosure parts | STEP |
| **Plate** | Switch mounting plate with cutout dimensions | DWG / DXF / PDF |
| **PCB** | PCB reference drawing | DWG |
| **Full Model** | Complete assembled 3D model | STEP |

## Opening the Files

| Format | Free Software | Commercial Software |
|---|---|---|
| `.stp` | FreeCAD, Onshape (browser) | Fusion 360, SolidWorks |
| `.dwg` | LibreCAD (limited), QCAD | AutoCAD, DraftSight |
| `.dxf` | LibreCAD, QCAD | AutoCAD, DraftSight |
| `.pdf` | Any PDF viewer | - |
