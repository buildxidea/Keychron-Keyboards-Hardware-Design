# Keychron C1 - Hardware Design Files

> Tenkeyless wired mechanical keyboard with USB-C connectivity, Mac/Windows support, and optional hot-swappable switches.

**Product page:** [Keychron C1 Wired Mechanical Keyboard](https://www.keychron.com/products/keychron-c1-wired-mechanical-keyboard)

![Keychron C1](https://www.keychron.com/cdn/shop/products/keychron-c1-hot-swappable-wired-mechanical-keyboard-tenkeyless-layout-for-mac-windows-non-backlight-keychron-switch-red-retro-style-color.jpg?v=1645785294&width=1200)

## Specifications

| Spec | Detail |
|---|---|
| Layout | TKL / 80% / ANSI |
| Number of Keys | 87 |
| Connection | USB-C wired |
| Frame Material | ABS |
| Keycap Profile | OEM |
| Polling Rate | 1000 Hz |
| Compatible System | macOS / Windows |
