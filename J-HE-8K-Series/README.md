# J HE 8K Series - Hardware Design Files

> Wired J-series Hall Effect gaming keyboards with 8K polling, magnetic switches, and Keychron Launcher customization.

Part of the [Keychron Keyboards Hardware Design](https://github.com/Keychron/Keychron-Keyboards-Hardware-Design) repository.

## Available Models

| Model | Layout | Size | Knob | Firmware |
|---|---|---|---|---|
| [J2 HE 8K](./J2%20HE%208K/README.md) | 75% | Compact | Yes | Keychron Launcher |

## Repository Contents

This series folder currently includes the J2 HE 8K model folder with published `stp`, `dwg`, `dxf`, and `pdf` downloads.

## Download Files

| File | Description | Format |
|---|---|---|
| [J2 HE 8K files](./J2%20HE%208K/README.md#downloads) | US plate, PCB, case, and full-model hardware files | STP / DWG / DXF / PDF |

## Opening the Files

| Format | Free Software | Commercial Software |
|---|---|---|
| `.stp` | FreeCAD, Onshape | Fusion 360, SolidWorks |
| `.dwg` | LibreCAD (limited), QCAD | AutoCAD, DraftSight |
| `.dxf` | LibreCAD, QCAD | AutoCAD, DraftSight |
| `.pdf` | Any PDF viewer | - |
