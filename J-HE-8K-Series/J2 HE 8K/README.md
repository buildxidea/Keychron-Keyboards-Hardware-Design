# Keychron J2 HE 8K - Hardware Design Files

> 75% wired Hall Effect magnetic switch keyboard with 8K polling, Keychron Launcher customization, a knob, and acoustic foams.

**Product page:** [Keychron J2 HE 8K Magnetic Switch Keyboard](https://www.keychron.com/products/keychron-j2-he-8k-magnetic-switch-keyboard)

![Keychron J2 HE 8K](https://cdn.shopify.com/s/files/1/0059/0630/1017/files/Keychron_J2_HE_8K_1.jpg?v=1772265921)

## Specifications

| Spec | Detail |
|---|---|
| Layout | 75% |
| Connectivity | Type-C wired |
| Polling Rate | 8,000 Hz |
| Switch Type | Keychron Ultra-fast Lime Magnetic Switch |
| Hot-swap | Yes, Hall Effect magnetic switch compatible |
| Mount Style | Gasket |
| Case Material | ABS plastic |
| Keycaps | Cherry profile double-shot PBT |
| Firmware | Keychron Launcher |
